# Swadhin Dibya Jyoti — Portfolio

A dark editorial portfolio built with React, TypeScript, Vite, Three.js, GSAP, and Lenis.

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local URL when the development server starts. Use that URL in your browser.

## Production build

```sh
npm run build
npm run preview
```

The supplied portrait is used only in the About section at `public/portrait.webp`.
